## Selected work

### NVIDIA · LSTP Config

During my NVIDIA software engineering internship, I implemented [LSTP Config](https://github.com/NVIDIA/lstp-config) from a concept proposed by my team, with guidance and reviews from the other contributors.

LSTP lets a host communicate through a single bridge to components on a target board. LSTP Config reads and writes board configurations using YAML. Instead of rewriting firmware for each board or chip, a hardware designer can write a short YAML file and run one command to achieve the same board-specific behavior with shared firmware. The tool supports forward- and backward-compatible configuration handling.

**C · Linux · libusb · YAML / libyaml · Embedded systems**
